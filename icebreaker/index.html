블랙박스 뉴런

연수 시작 10분, 숨은 퍼셉트론의 규칙을 모둠별로 추리하는 아이스브레이킹

실험실로 →
진행 안내
준비물: 이 화면(프로젝터), 모둠별 메모지. 3~4명씩 모둠을 만들어 진행합니다. 퍼셉트론을 몰라도 참여할 수 있습니다.
  1. 규칙 소개1분
    “이 상자 안에는 입력을 받아 0 또는 1을 내는 기계가 숨어 있습니다. 입력을 넣어 보며 이 기계가 어떤 규칙으로 움직이는지 알아맞혀 보세요. 적은 횟수로 맞힐수록 이깁니다.”
  2. 모둠별 신호 보내기3분
    모둠이 돌아가며 입력 하나를 정해 부르면 진행자가 ‘신호 보내기’를 누릅니다. 결과는 모두가 함께 보므로, 어떤 입력을 물어볼지가 전략이 됩니다.
  3. 규칙 말하기2분
    규칙을 알아낸 모둠은 손을 들고 말로 설명합니다. 예: “둘 다 1일 때만 불이 켜집니다.”
  4. 가중치와 편향 찾기3분
    아래 식을 보여 주고, 같은 출력을 내는 w와 b를 모둠별로 메모지에 적게 합니다. 오른쪽 칸에 넣고 ‘모든 입력에서 확인’을 눌러 검증한 뒤 ‘정답 공개’로 상자 속 값과 비교합니다.
  5. 한 판 더 (시간이 남으면)3분
    ‘새 블랙박스’로 바꾸거나 ‘입력 3개’로 난도를 올립니다.
z = w1x1 + w2x2 + b,   y = 1 (z ≥ 0),  y = 0 (z < 0)
